# Bandit Level 0

## Objective
Connect to the OverTheWire Bandit server using SSH.

## Connection Details

- **Host:** `bandit.labs.overthewire.org`
- **Port:** `2220`
- **Username:** `bandit0`
- **Password:** `bandit0`

## Command Used

```bash
ssh bandit0@bandit.labs.overthewire.org -p 2220
```

## What I Learned

- SSH (Secure Shell) provides secure remote access to another system.
- The `-p` option specifies the port used for the SSH connection.
- Linux servers can be accessed remotely through a terminal.
