# Bandit Level 0 → Level 1

## Objective
Find the password for Bandit Level 1.

## Commands Used

### 1. List directory contents

```bash
ls
```

Used to identify files in the current directory.

### 2. Read the file

```bash
cat readme
```

Used to display the contents of the `readme` file.

### 3. Exit the SSH session

```bash
exit
```

Used to terminate the remote shell session.

## Concepts Learned

- `ls` — listing directory contents.
- `cat` — reading file contents.
- `exit` — closing a shell session.
- Linux files can be inspected directly through terminal commands.

## Result
Successfully retrieved the password for Bandit Level 1.
